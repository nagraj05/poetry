# ✒️ Bronte

*A minimalist poetry library — where ink meets eternity.*

Bronte is a thoughtfully designed web experience for discovering and curating poetry. Built with a focus on elegance, performance, and modern web standards.

---

## ✨ Features

- 🖋️ Minimal, editorial-style design  
- 🌗 Dark / Light mode support  
- ⚡ Fast, app-router based Next.js architecture  
- 🎨 Modern UI with smooth animations  
- 📱 Fully responsive across devices  

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **UI**: React + Tailwind CSS
- **Icons**: Lucide Icons
- **Fonts**: Geist (via `next/font`)
- **Theme**: System-aware dark mode
